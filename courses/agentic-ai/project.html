🏁 Final Project

Build a real support-triage agent, check it automatically on GitHub, and earn the Certified Agentic AI Engineer certificate.

🎯 The brief

Build an agent that reads incoming support tickets, looks up answers in a knowledge base, drafts replies with citations, and asks a human before sending anything. Any language and any LLM provider are fine.

  • Tool use with at least 3 well-described tools.
  • An MCP server that exposes at least one of those tools.
  • Retrieval over a knowledge base, with citations in the replies.
  • Human approval before any irreversible action, in a function you name in the manifest.
  • Injection resistance: text inside tickets is data, never instructions.
  • An eval suite of at least 20 tasks, including injection and approval tasks.
  • Tracing that records each step with its tokens (and cost, if you can).
  • Limits on steps, time and spend, with a graceful fallback message.
  • A README (Setup, Architecture, Design decisions), a reflection of 150+ words and a demo video link.

🛠️ Set up your repository

  1. Create a public GitHub repository for your agent.
  2. Add the starter files and fill them in:
    agentic-ai.json evals/tasks.jsonl evals/run_evals.py traces/example.json README.md REFLECTION.md
    agentic-ai.json tells the checks where your MCP server, approval function, eval command, trace and reflection are.
  3. Save the workflow as .github/workflows/agentic-ai-verify.yml, unchanged:
    ⬇ agentic-ai-verify.yml
  4. If your evals call a model, add your key under Settings → Secrets and variables → Actions as ANTHROPIC_API_KEY (or LLM_API_KEY for another provider). Each check run uses your key, so keep the eval set small enough to be cheap.
  5. Push to your default branch. The Actions tab shows the run and which checks passed.
  6. When the run is green, submit your repository below.
